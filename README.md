# Password Generator

A simple password generator built with Python.

## Features

- Generate random passwords
- User chooses password length
- Uses letters, numbers, and symbols
- Easy to run from the terminal

## Technologies Used

- Python

## How to Run

1. Download the project
2. Open a terminal in the project folder
3. Run:

```bash
python password-generator.py
```

## Example

How many characters should the password have? 12

Generated Password:
hCOFIX#iU%H9
